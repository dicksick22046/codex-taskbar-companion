# 更新记录

[English](../../CHANGELOG.md) · **简体中文**

## Unreleased

## 0.8.0

- 新增自动摆放：优先主任务栏，空间不足时转为悬浮窗，空间稳定恢复后自动返回。
- 新增悬浮显示器选择，支持跟随主屏、断开后临时回退及重连恢复，保留相对位置。
- 面板、菜单和新打开的工具窗口跟随目标显示器，自动模式避让前台全屏应用。

- 配平底栏选中态在圆环和文字两侧的留白，使反馈背景与点击区域一致；状态计数直接加强自身底色，不再叠加外框。

## 0.7.0

- 重构设置界面：固定侧栏、清晰的文字层级、均衡的控件间距，以及可直接选择的显示位置和配色。
- 更新任务查找、面板材质、单位选择和项目标签，保留原有圆环比例过渡与轮换行为。
- 设置立即影响胶囊尺寸；单位同步到各窗口，主动筛选回到列表顶部，后台刷新保留当前选择。
- 修正快速切换、隐藏后恢复、键盘操作及关闭系统动画时的动效状态。
- 新增可选、合并去重的待回答通知；任务跳转、自启和设置保存失败时提供可见反馈。
- 新增复制诊断信息，仅包含允许的运行状态，排除任务内容、账号、路径与日志。

## 0.6.1

- 设置仅点击开关才修改，点击说明和行内空白不再误触。
- 单位、任务和菜单在松开时执行，拖离可取消；按住任务时固定内容，避免轮换错点。
- 滚轮不再意外更改设置或任务筛选，面板支持触控板精细滚动。
- 任务面板补齐键盘导航、局部焦点提示；底栏尊重实际窗口遮挡。
- 开关和面板动画可从当前状态平滑反向，遵循 Windows 动画选项，隐藏内容停止动画循环。
- 优化标签页、按压反馈和空状态，保留不透明面板和内置字体。

## 0.6.0

- 查找任务增加本机累计运行时长、Token和执行轮次，支持点击表头排序与M/100M单位切换。
- 查找窗口打开时分批整理历史，缓存读取位置；不完整记录显示保守下限。
- 设置改为外观、显示项、常规三组，控件对齐，开关支持整行点击和键盘操作。
- 明确未回答的同步提问显示「待回答」分类及问号计数，停止生成动效，点击返回Codex处理。
- 不把自动审核事件当成人工审批，不更改现有审批策略。

## 0.5.0

- 胶囊按内容收窄，保留原有最大宽度；任务轮播不反复伸缩，悬浮时保持左侧位置。
- 右键增加查找任务，可按名称、项目搜索和筛选，支持键盘选择及跳转。
- 任务目录纳入已记录的CLI执行和app-server来源，按任务ID去重；新纳入的本机记录会进入既有用量统计。
- 完整搜索目录仅放内存，不写诊断文件；未命名任务按当前语言显示。
- 复用字体配置，减少绘制时的重复设置。

## 0.4.0

- 新增可选悬浮胶囊，支持拖动、记住屏幕内位置和开关置顶。
- 悬浮面板根据空间向上或向下展开；长重置列表可滚动，操作按钮保持可见。
- 设置窗口在较小屏幕上可滚动，语言切换后下拉框宽度随文案调整。
- 减少无变化时的重绘和设置刷新，任务动画仅刷新任务区域。
- 诊断快照改为每30秒及退出时写入；实时数据与额度、重置记录的保存不变。

## 0.3.3

- 增加胶囊左侧内边距，避免圆环贴近边缘。

- 底栏增加固定宽度胶囊，可在设置中手动选择深浅配色和背景透明度。
- 修复原生窗口状态与Qt不同步导致底栏消失；右键菜单置于底栏及任务栏上方。
- 左侧指标轮换时隐藏底栏分隔线。
- 重置历史中的Tokens/用量、数值和单位分别按列对齐。
- 重置历史统一按亿（100M）显示，每条记录保留单位，不再自动切换M/B。
- 轮换数值改为靠近说明的左对齐列，保持圆环原位。
- 周期用量标题精简为“Cycle · Tokens”，同步精简其他语言文案。
- 按当前倒计时格式收紧轮换区，保持圆环原位和轮换过程中的宽度稳定。

## 0.3.2

- 轮换时说明靠左、数值靠右，使分隔线两侧留白对称。
- 重置倒计时加入轮换，所有已开启的左侧指标共用一个固定宽度位置。
- 侧聊结束后按其自身的Codex未读状态合并到父任务，保留未读和Side标记，查看后随Codex清除。
- 重置历史始终按该次事件标注额度窗口，当前只有周额度时也显示7d。
- 重置历史每行显示用量说明和单位，分类前增加细分隔线，分类文字统一为蓝色。

## 0.3.1

- 修正重置历史为从早到晚排列：7号在上，8号在下。

## 0.3.0

- 重置历史按发生时间从新到旧显示，补入旧记录也不会打乱顺序。
- 支持英文、简体中文、日语和西班牙语界面，切换立即生效并保存。
- 新增可选额度轮换，固定占用一个位置，倒计时独立；阅读或点击时暂停，文字和圆环连续过渡。
- 调整语言选择框样式，并排与轮换使用同一套短标签。
- 支持悬停打开面板，移入与移出都有短暂延迟。
- 侧聊使用独立 Side 标签，状态条重启后保留已确认的侧聊关联。
- 修复 Windows 任务栏盖住状态条的问题，恢复显示时不激活窗口。
- 重置默认优先使用最早到期的机会；历史用量使用 100M 单位，重置面板更紧凑。
- 统一缺少数据时的显示。仓库文档默认英文，提供多语言 README 和中文更新记录。

- 重置历史增加各阶段本机已收录的 Token 用量，来源配色收敛，保留可用次数与默认项的强调色。
