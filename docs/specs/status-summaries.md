# 自动状态摘要与本次收起

## 显示与关闭

取代按状态持久置顶：待回答、进行中、未读、失败默认自动显示摘要，每个有内容的状态占一行，仍共用底栏上方的连通面板。主动停止和最近任务保留底部/菜单列表入口，不自动常驻。已有“显示任务状态”总开关继续有效。

摘要行右侧使用 Lucide 关闭图标，12 DIP 图形、26 DIP 命中区；仅整行悬停或按钮键盘聚焦时显示，保留按下和焦点反馈。关闭只收起该状态当前一批任务，不取消或标记已读，不跳转任务。整行其余区域仍可打开任务。移除摘要和状态详情中的图钉及持久置顶操作，不新增开关。

## 恢复规则

每个状态的关闭记录包含当时所有成员的任务 ID 和执行轮次标识（优先 turn_id，侧聊使用已有 started_at）。同一批次刷新、计时、轮换、名称变化和成员减少不恢复。新 ID、新轮次进入该状态时恢复该状态整行，先展示新到项，再恢复普通轮换。明确观察到某任务离开该状态后，旧的关闭标识失效；以后重新进入即为新事件。数据读取错误、加载中、未知未读值或任务暂时缺失不当成新的进入事件。

关闭记录按账户隔离，持久保存在本机 status_dismissals.json；只有任务身份、轮次和分类，不保存正文。重启恢复同一批次的收起状态，账户暂时不可确认时不混用账户记录。成功读取新状态后清理已过期的关闭标识；写入失败保持本次内存行为并记录本机错误，不伪称跨重启保存成功。

独立状态之间没有关闭继承：进行中转入未读、待回答或失败时，对应状态按自身规则出现。旧 pinned_statuses/show_task_strip/task_strip_position 设置退休，不继续解释为永久关闭；其他设置和历史数据保留。

## 交互与验证

保留每行独立 8 秒轮换、悬停/按住/拖动/隐藏暂停、长标题阅读、运行反馈、单任务入口直达和共同动态外宽。详情仍临时替代摘要，关闭详情恢复当前未收起的状态；数据更新即使发生在详情打开期间也应正确处理。

验证默认四状态、停止不常驻、整批关闭、子集不重开、新任务/新轮次恢复、状态往返、未知/失败快照、重启和账户隔离、关闭不会跳转/消费重置、鼠标悬停及键盘焦点、四语言深浅色与减少动画。旧置顶测试改为相应的新合同验收，不保留仅为旧测试使用的置顶兼容接口。
