# 价格同步规范

## 目标

在任务栏伴侣更新到新版本后，或本机日志首次出现未收录的模型标识时，后台核对 OpenAI 官方 Standard API 价格，让新模型尽快获得 USD 等值估算。同步不读取账号凭据、任务正文或原始通信，不阻塞任务栏启动，也不启动或控制 Codex。

## 来源与校验

- 唯一远程来源为 `https://developers.openai.com/api/docs/pricing.md` 的 Standard pricing 表。
- 价格行必须包含精确模型 ID、短/长上下文的输入、缓存输入、缓存写入和输出费率；表结构或字段变化时整次同步失败。
- 只接受非负有限数字和明确的 `-` 空值；未知模型不按前缀或相近名称匹配。
- HTTPS 请求限制响应大小和超时；账号网络失败、官方页面不可用或解析失败时保留上次有效缓存与内置价格。
- 远程结果只写入本机价格缓存，不修改源码价格表、不执行代码、不上传本机数据。

## 触发

- 每次进程启动比较当前 `VERSION` 与价格缓存的 `checked_app_version`；版本变化时后台同步一次。
- `UsageCursor` 发现未收录模型 ID 时发出去重请求；同一模型在当前进程只触发一次，失败后下次启动可重试。
- 删除现有每日定时价格检查；保留手动 CI 入口和价格文件变更时的 CI 校验。
- 同步任务只由 Provider/应用内后台线程执行，UI 继续使用上一份快照。

## 缓存与计价

价格缓存保存于 `%USERPROFILE%/.codex-taskbar-companion/pricing_cache.json`，包含来源 URL、抓取时间、触发应用版本、模型费率和校验状态。缓存条目使用精确模型 ID。

- 内置 `RATES` 是离线兜底；有效的官方缓存可补充内置表中不存在的新模型。
- 缓存费率仅用于抓取成功后的新日志事件；已有事件不按新抓取时间之前的费率追溯重算。
- 每条计价事件保留其解析时采用的价格来源时间；无法证明模型、用量或价格时继续返回 `None`，聚合继续保持未知值语义。
- 价格缓存损坏、过期格式或不完整条目被忽略并回退到内置表。

## 交付与验证

- 维护者仍需把稳定模型和费率写入 `pricing.py`、`standard_model_ids.txt` 及文档，保证离线安装包可用。
- CI 不自动改价或发布；客户端同步只补充经过官方表校验的新模型。
- 测试覆盖版本变化触发、未知模型去重、官方表解析/结构变化、缓存原子写入、网络失败回退、价格生效时间边界和现有 USD 完整性规则。
