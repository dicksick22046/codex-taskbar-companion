# 首版产品审查

本轮使用实际运行的Windows窗口截图，内部截图在忽略的.runtime/release-audit目录。

1. 主状态条：指标与任务分区清楚，维持现有设计；补任务栏空间不足时收起，避免遮挡系统按钮。
2. 用量面板：保持周期图表；新增可用5h窗口的独立摘要，避免将两个重置周期混淆。
3. 任务面板：保留紧凑信息组和状态标记，不扩展成本或多服务商。
4. 设置入口：原先不存在；已加入右键与托盘入口、五项显示开关、启动和更新。后台启动首个普通窗口被Windows隐藏的问题已修复。
5. 恢复入口：全部显示关闭后主条隐藏，设置仍可还原；再次启动应打开已有实例设置。
6. 发行：每用户安装，数据与代码分离；实际安装、覆盖更新和卸载验收在最终交付前完成。

键盘可使用原生菜单及复选框；透明自绘状态条未做完整屏幕阅读器审计，不宣称全面无障碍合规。macOS、多屏独立组件及全面实时故障检测不在首版范围。

最终验收：两项右键菜单、安装版设置、五开关和隐藏恢复通过；安装、覆盖更新重启、卸载保留数据通过。修正了外部ICU混入和窗口透明属性顺序回归。57项测试通过。公开仓库为dicksick22046/codex-taskbar-companion，公开发行记录以GitHub Release为准。
