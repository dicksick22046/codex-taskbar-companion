# v0.2 分区面板与额度重置

新增悬浮显示的几何、拖动与设置约定见[Windows companion](windows-companion.md)。下面涉及任务栏锚点的约束用于Taskbar模式；Floating模式复用相同数据与内容，由屏幕可用区域决定面板方向。

## 点击与信息

- 周额度打开既有周期图表；可选5h额度打开独立短周期面板，显示剩余额度、具体恢复时间、本窗口已记录的余额时间曲线。复用30秒采样，切换窗口后重新记录，不补造历史；是否显示按真实300分钟窗口决定。日额度打开Today · Tokens列表，仅保留各任务今日Token，不显示时长。
- 日列表分Needs input、Running、Unread、Failed、Stopped、Recent；任务只出现一次，空分组隐藏。待回答按attention.md中的明确请求配对识别。组内按今日Token降序，再按最近活动排序。不把本机Token解释为账户额度百分比的精确分摊。
- 状态胶囊（圆点和数量整体）只打开对应分类列表，仅显示本轮耗时，不显示Token。运行中持续计时；未读、停止、失败保留最近一轮的开始至结束时长。缺少必要时间则未知，不用今日累计时长代替。
- 底部仅在数量非零时显示Running、Unread、Failed、Stopped胶囊。保留已有状态证据边界，不增加网络失败推断。
- 项目标记与滚动标题整体点击直接打开当前任务。悬停暂停轮播，按下时固定目标，松开仍在该点击区才执行；空白、拖离不跳转。
- 打开及关闭悬浮框不改变底部轮播计时；悬停任务暂停，离开后保留之前已等待的进度，不重新等待完整8秒。按住点击或重置确认期间仍暂停。
- 同时只开一个面板；同入口再次点击关闭，不同入口切换，外部点击关闭并正常传递。无运行任务时不再保留Tasks占位；右侧为空时也不绘制分隔线，今日列表由日占比进入。
- 设置增加“悬停打开面板”，默认关闭并持久化。开启后，额度、倒计时和状态计数入口停留350毫秒打开/切换；短暂扫过不打开。进入面板或入口时保持打开，离开两者450毫秒关闭，允许跨越8 DIP间隙。点击仍可立即开关；点击关闭后，同一入口需移开再悬停才重开。滚动任务标题继续点击跳转，不由悬停触发导航或重置。设置、菜单与重置确认显示时暂停悬停触发。
- 所有面板复用现有字体、颜色、左边界、8 DIP任务栏间距及单行任务布局。背景统一为不透明深色，禁用毛玻璃及背景透色，保留圆角与开合过渡；不增加常驻提示或设置项。

## 额度轮换

设置增加“轮换左侧指标 / Rotate left-side indicators”，保存 rotate_quotas 布尔值，默认关闭。开启时，已开启且可显示的周剩余额度、今日额度消耗、5h剩余额度和重置倒计时共用一个位置，按周、日、5h、重置顺序每8秒切换。无5h窗口跳过，只剩一项不轮换，无候选不占位置。并排模式保持原布局与原文案。

轮换项显示 Week / Today / 5h（中文为周 / 今日 / 5h）与原数值，仍分别表示周剩余、今日消耗和5h剩余；数据缺失保留统一横杠。单槽按当前倒计时的天/小时/分钟格式预留宽度，说明列与数值列之间留3DIP；不提前为尚未出现的更长格式占位。同一格式内所有轮换项共用宽度，圆环位置不变；只在格式或显示开关变化时重新计算。过渡保留旧内容，460ms缓入缓出；文字交叉淡化并作14DIP纵向交接，圆环原位插值颜色和弧长，不清空再出现。点击按当时更清晰的内容确定目标，过渡可从当前进度平滑回到该项，不新增滚动条或分页点。

鼠标进入额度槽、对应面板（包括重置面板）打开、按住按钮、设置/菜单或重置确认显示时暂停轮换；离开后续用已等待的进度，不重新等待完整8秒或立即补跳多项。点击打开按下时对应的面板；悬停模式也使用同一入口，不因自动轮换换成另一面板。候选因开关或实际窗口变化而移除时选择首个可用项；短暂数据读取失败仍遵循保留有效记录规则。

复用现有UI tick与Qt过渡，不增加Provider采样、后台线程或文件轮询。额度与任务轮播独立；语言切换不重置轮播进度。验证还需覆盖稳定宽度、按下期间切换边界、长时间悬停后恢复、开关保存、候选减少与全部关闭。

轮换槽内说明和数值均左对齐，数值列从最宽说明后3 DIP处开始；圆环坐标不变，短数值剩余空间留在末尾，不再通过两端对齐拉开中间间距。槽宽在同一倒计时格式内固定，文字进出仍同步过渡。轮换模式不绘制指标与任务区域之间的竖线，保留组间空白和点击分区；并排模式继续显示分隔线。

## 重置面板

剩余时间独立打开重置面板：下一次周期重置时间、已观测记录、使用一次重置按钮及默认机会到期时间。复用account/rateLimits/read既有30秒读取，不增加采集线程或轮询。

默认选择最早到期的有效可用机会；到期时间相同优先较早发放的，没有到期时间的放最后。列表与默认选择共用此顺序，不提供机会展开或选择器。所有机会直接列出expiresAt，默认项有简短标记；未知不声称永不过期。明细不完整、无法确定默认机会或账号未知时，不猜测消费对象。已经发送但结果未明的请求继续使用原机会和幂等键，不因排序变化而更换。

点击按钮必须二次确认，明确消耗一次机会及该机会到期时间。确认框与原按钮位置分开，取消为默认按钮；取消不发送请求。确认后请求进入现有Provider线程串行执行，先重新读取并核对账号与选中机会；按钮立即进入处理中，防止重复提交。

每次操作在请求前持久化账号、creditId与UUID幂等键。超时或连接结果不明时保留同一次请求；后续用户明确确认重试才继续，重试不得换机会或换幂等键。启动程序不会自动消费机会。账号切换不能执行其他账号的未决请求。

只有reset或alreadyRedeemed才记Manual，并重新读取额度；noCredit、nothingToReset不记成功。未知结果不标成功。错误只记本机日志，操作按钮提供可重试状态，不弹全局提示。

## 记录与数据

记录按账户分开保存在用户数据目录，保留最近100条。界面按事件时间升序显示，较早记录在上（例如7号在8号上方），不依赖文件中的写入顺序；阶段统计仍按时间升序划分。新版本开始观察，不把无账户归属的旧采样拼成完整历史。每条时间为确认或观察时间。

- Scheduled：已知窗口到期并观察到下一周期。
- Manual：本工具的重置请求已确认成功。
- Official：按用户指定的排除规则归类，已观察到额度恢复，且不属于自然到期、没有本工具手动成功记录或未决请求。该分类是产品推定，不表示已核验官方公告；数据保留classification=inferred。

赠送重置机会不等于额度已重置。仅恢复时间变化、余额未恢复且原窗口尚未结束，不记重置；服务端恢复时间的秒级调整不能产生历史事件。自然到期要求跨过旧周期末且进入新周期；提前变化必须观察到余额恢复。新观测保留变化前后窗口作为依据，并按Scheduled或Official归类。手动成功及未决操作优先，不重复记为Manual与Official。不查询新闻，不新增轮询或界面提示。外部手动操作没有被现有数据记录时，也会按上述规则归为Official。

有前后窗口依据的旧Unknown记录按同一规则回算，保留时间与ID；仅时间抖动的旧误报丢弃，没有窗口依据的旧记录不臆造事件事实。发生同一窗口内用量下调时，今日消耗保留此前已观察到的正增量。

重置面板统一英文：Next reset、History、Expires。历史与到期时间各自单列左对齐，来源和默认标识右对齐；始终按该次事件记录的窗口附7d、5h或5h + 7d标记。三次机会直接列出，单个Reset quota按钮独占底部，不与日期同排。分组间用弱分隔线，复用现有字体和功能色，不增加图标、边框或交互层级。

重置面板以300 DIP为最小宽度，按时间、用量和分类的实际字宽补足空间，与其他面板左边界对齐。日期、用量、来源保持三列，数字列根据来源标签实际字宽定位；按钮随面板宽度收窄，并减少其上方8 DIP空白。其他面板宽度不随之改变。

重置来源统一为蓝色；可用次数保留绿色，默认项和下一次重置时间使用蓝色。底部每个点击矩形统一接收鼠标，不能因字形之间的透明像素而穿透；其余空白保持穿透。日单位悬停与刷新使用同一命中判断，悬停不改变已选单位。

## 侧边聊天与历史阶段用量

Codex侧边聊天是临时会话，不进入普通任务列表和持久化rollout。复用Provider的目录更新节奏，只读当前桌面进程的日志：用thread/fork的requestId关联核心日志中的新thread_id，要求子任务未落入普通threads表且父任务可识别，再将该临时会话的turn/start、turn/interrupt及turn-complete作为状态依据。日志变化只读新增部分，关联仅在新fork出现时查询索引范围，不增加常驻线程、不读取或保存对话正文、不改Codex配置。

完成通知未弹出时，复用同一日志中的`[browser-session-registry] IAB_LIFECYCLE ended browser use session activity`元数据清除关联侧聊的运行态。已核对当前桌面实现：原生`thread/status/changed`变为`idle`，以及开始中断时，会结束该会话活动。它仅说明停止运行，不单独证明成功或失败；后续清理不得覆盖已确认的完成/中断原因。没有明确完成通知的闲置侧聊，只有其ID仍在Codex原生未读集合中才合并为未读。普通任务状态不采用独立观察进程返回的`interrupted`来覆盖真实运行日志。活动时间比较使用时间点，不对不同时区的ISO字符串排序。

已确认的子任务ID与父任务ID关联保存到本工具数据目录，按Codex桌面进程会话隔离。状态条重启时恢复关联，避免核心创建日志清理后失联；不缓存运行状态，仍重放当前桌面日志判断开始与结束。Codex会话变化或进程退出后不沿用旧关联，不按时间接近猜测新关联。

主任务与侧边聊天分别作为状态项，按各自ID计数；同时运行时计为两项，多个侧聊各计一项。有关联侧聊的主任务显示Main标签，侧聊显示Side标签并沿用父任务标题和项目，保留parent_id；不把父任务改成侧聊的状态。各项独立进入Running、Needs input、Unread、Stopped、Failed或Recent。侧聊没有对应证据的状态不从父任务继承，原生空闲记录不冒充失败或成功。普通分叉、子代理仍不加入本次区分范围。

侧聊本轮时间使用自己的开始和结束记录。侧聊无持久化日志时，Token、全历史时长及轮次保持未知，不复制父任务用量，汇总不重复相加。底栏、分类悬浮、今日列表与任务搜索使用同一批独立状态项。Main/Side标签沿用中性色小方块，标题继续使用真实父任务名称；点击Side回到所属父任务，避免用临时ID打开不存在的独立任务页。Codex桌面重启后不沿用旧临时运行态；日志不可用时不伪造侧边状态。

重置历史每行显示该次重置前一个阶段的本机Token总量，标题只显示History，每行增加用量说明与单位；统一按100M缩放，中文和日文使用亿/億，英文和西文使用×100M，不按数值大小改用M/B；用量与分类之间增加细竖线。区间为前一次记录时刻到本次记录时刻，首条优先用其原窗口起点；无边界依据时留空。复用UsageCursor的累计差分和分叉继承排除，首次回溯覆盖所需阶段，之后按原有日志增量累计；不重复扫描整份文件、不新增采样线程。阶段边界按观测时间划分，不能声称为账户跨设备精确额度或含未落盘临时会话用量。周图和日用量原有统计边界不变。

周图和日列表顶部分别保留“Cycle · Tokens”和“Today · Tokens”小标题；下方共用图标、日期周期、Σ Token总量、M / 100M单位切换。日列表日期为本地当天，总量使用现有今日累计Token，单位同时作用于总量与任务行。周图保留柱状图；状态与重置面板没有单位点击区域。

历史用量分列绘制：Tokens/用量说明左对齐、数值右对齐、单位左对齐；各行共用列坐标，缺失数值显示横杠，不挤动其他列。

### 侧聊结束后的未读

侧聊元数据保留完成与中断的区别。完成或已空闲的侧聊，只有其子会话ID存在于Codex现有未读ID集合时才显示为独立Unread项；不要求父任务自身存在未读记录。查看后随Codex移除子会话未读ID而清除，不写Codex状态、不按停留时间推测已读、不新增未读数据库。

主任务仍运行时，其Running与侧聊的Unread可同时存在；各项不会互相覆盖。中断不冒充完成；未读源不可用时不编造未读。关联缓存与日志重放继续复用现有链路。

支持Codex当前`electron-thread-read-state-v1`未读格式：严格选择当前登录身份和本机执行来源，不能合并其他账号、远程主机或旧迁移快照。身份键遵循已核对的桌面算法，利用既有Provider的30秒读取节奏调用本机`getAuthStatus`解析必要身份字段，只保留哈希，不记录Token或凭据；身份变化使未读缓存失效。现代结构存在但身份不可确认时返回未知，不退回陈旧旧格式；现代结构不存在时仍读取旧版本的本机未读字段。

## 界面语言与术语

底栏使用固定宽度胶囊背景，沿用现有区域，内容起点为18DIP，圆环在轮换时保持原位，不自动伸缩或跟随系统主题。设置提供手动深色/浅色配色与背景透明度0%～100%，保存在capsule_theme和capsule_transparency，默认深色、0%透明（不透明）。文字、圆环及状态色使用对应配色，透明度只作用背景，不使用整个窗口的透明度。面板、菜单和设置窗口维持现有深色样式。胶囊空白不触发面板，外部圆角区域仍透明；所有关闭时不显示胶囊。

配色立即生效，滑块拖动实时预览、松开保存，键盘调整也保存；不新增背景采样、系统主题监听或采集线程。所有四种语言提供对应文案。原生可见恢复和菜单层级修复继续有效。

设置提供 English / 简体中文 / 日本語 / Español，保存在现有 ui_settings.json 的 language 字段（en / zh-CN / ja / es）；未配置或无效值默认英文。切换立即更新设置、右键菜单、底栏、已打开面板与更新状态，不重启采集、不改变统计、单位、开关或任务轮播进度。

应用自有文案集中在一份中英词表：No project / 无项目，Side / 侧聊，Running / 进行中，Unread / 未读，Failed / 失败，Stopped / 已停止，Recent / 今日其他；额度表示账户百分比，Tokens 表示本机记录的 Token 用量，二者不混称。周面板为 Cycle · Tokens / 周期 · Token，日面板为 Today · Tokens / 今日 · Token。重置来源沿用既有分类，仅翻译标签，不改变判断。

底栏并排与轮换使用同一套短标签：Week / 本周、Today / 今日、5h、Reset / 重置。前两种额度窗口仍表示剩余，今日表示消耗；“本周”为周额度的简写，统计继续跟随账户当前滚动周期，不改为日历周。倒计时不再只显示孤立时长，语言变化后按实际字宽定位。

数据层无项目用空字符串表示，由显示层产生占位；真实项目名与任务名不翻译。产品名、Token、M / 100M、5h / 7d、紧凑时间缩写和日期格式保持一致。用于单实例通信的隐藏原生主窗口标题保持不变；安装器使用其独立语言流程，README 与更新记录继续中文。

语言切换后按实际文本重新计算项目与侧聊标签、重置来源列宽，避免中英文遮挡。验证覆盖两种语言的设置/菜单/全部面板/确认框/更新状态、持久化、原始任务名称与模拟重置取消；不触发真实重置、不接管鼠标。

## 验证

底栏仅在布局允许显示时恢复窗口。同时核对Qt可见状态、原生可见/最小化状态及QWindow曝光状态；不能仅用QWidget.isVisible判断。短暂未曝光留300ms缓冲，每次持续异常只恢复一次，正常曝光后才允许下次恢复，避免锁屏或遮挡期间反复闪动。恢复通过Qt自身hide/show同步表面，再绑定任务栏和更新绘制，不重启进程、不新增轮询线程。菜单和重置确认期间不重建父窗口。

右键菜单归属于状态条且保持在其上方；从底栏打开时放在任务栏上方8DIP并限制在可用屏幕内。重新绑定任务栏时只放到任务栏前面，不无条件升到其他弹窗前面。

分类互斥、空组隐藏、日Token与本轮时间口径、点击分区/按下目标固定/拖离取消、列表跳转、重置到期优先排序与选择、二次确认取消、重复点击、超时重试幂等、重启/账号切换、自然与提前重置分类、旧记录回算、同窗口重置后的今日累计均需针对性验证。
