# Windows Codex 状态条

v0.2的点击分区、单列任务信息与重置操作以[当前交互规范](interaction-v0.2.md)为准，以下早期交互描述不覆盖该规范；字体、绘制与窗口材质规则继续沿用。

## 展示与交互

0.2.2毛玻璃统一使用80%不透明度的中性深色原生Acrylic底色，保留背景模糊与透色，避免浅色窗口透入后冲淡正文。打开面板不再暂停底部轮播；其他交互以interaction-v0.2.md为准。

独立透明单行窗口，按用户最新要求统一使用阿里巴巴普惠体 3.0 Regular（官方文件 Version 3.01），字体内置仅注册本进程，QPainter 抗锯齿，无外框或操作提示。登录 Windows 后自动启动，保留开始菜单入口。
字体采用灰度抗锯齿及 PreferNoHinting，避免透明背景下的子像素彩边。基础字号相对原版增加 0.5pt：正文 9.5pt，辅助信息 8.5pt，图表小字 7.5pt，保持常规字重。
主栏依次为绿色周余额环、紫色今日消耗环、蓝色剩余时间环及可读倒计时，竖线后为轮换任务。三个环复用 11 DIP 直径、1.4 DIP 线宽及物理像素对齐；未知日额度保留淡色短横杠。运行绿点呼吸，每 8 秒轮换任务，项目标签与任务名整体用 450ms InOutCubic、22 DIP 上下位移与交叉淡入淡出交接；悬停标题或打开面板暂停，离开后重新计时。
项目名使用细线圆角标签，有项目蓝色描边，无项目中性灰；与任务标题之间留白，不使用连接点、文件夹或对话图标。项目标签宽度受限，任务标题保留主要空间。
底部呼吸点与进行中总数合成一个小胶囊：18 DIP 高、淡绿色半透明底、无描边，左侧绿色呼吸点，右侧 8.5pt 常规浅绿数字。数量按任务 ID 去重，与任务列表来源一致；无运行任务时隐藏。计数不随轮播移动，后面的项目使用原有细线标签，避免两者混淆。
主栏进行中的任务标题加入从左到右的柔和文字扫光：2.6 秒扫过、0.6 秒间隔，亮光只作用于字形，不绘制背景光带。复用现有动画时钟，字体及布局不变；没有运行任务时不绘制。悬停阅读正在横向滚动的长标题时暂停扫光。
运行标题基色为 #8797AA，扫光中心 #F4FCFF，明暗对比明确。两个弹窗共用原生深色 Acrylic 模糊、半透明暗色蒙层与系统圆角，背景颜色可透入但后方文字需模糊，文字和图表不单独降低透明度。整窗透明度控制开合过渡，让材质与内容一起淡入淡出，不出现额外边框。底部状态条仍完全透明。
左侧三个数值为 8.5pt、右侧标题为 9.5pt，均为常规字重与 #8797AA 基础颜色；运行标题的扫光高亮独立保留，三个圆环的功能颜色不变。

整组交接期间暂停文字扫光，标签不能先于任务名跳变，新旧文字不在同一基线上叠加。

用量图顶部在日期与单位之间显示 Σ 周期累计 Token，累计值取本周期图表已记录的有效数据，排除未来日期，缺失不当作零；与柱状图共用 M / 100M 切换，不增加一行标题或扩大弹窗宽度。

玻璃材质降低暗色遮盖：原生 Acrylic 使用更通透的中性蓝灰调色，Qt 只加约 9% 暗蒙层与非常轻的顶部柔光；两面板共用绘制，不添加外框。验收分别检查两个实际弹窗，不以参数启用代替可见效果。
左侧指标点击打开图表，右侧打开任务列表。同一区域再次点击关闭，跨区点击直接切换；无运行任务也保留任务入口。外部点击关闭并正常传递，移出不关闭。面板不抢焦点，仅点击任务激活 Codex。无关闭 X，动画可中断。
弹窗创建时即设置真实窗口透明度为 0，在隐藏状态完成布局与毛玻璃配置，再显示并启动淡入；动画数值为零不能代替原生窗口透明度初始化，禁止先显示实色首帧。
状态条通过公开 Win32 owner 关系保持在任务栏上方，随任务栏层级升降；不周期性抢占置顶，不激活前台。开始/搜索菜单打开时不能遮没状态条。任务栏重建导致原生窗口销毁时，保留数据提供器并重建自己的窗口，再关联新的任务栏；不重启 Explorer 或注入其进程。
用量图不含任务；顶部日期范围后只追加一次重置时间，右侧 M / 100M 切换并保存。普通日期蓝色，今天绿色，已结束有效日期的极值紫色，相同值不强调；未来、缺失、零值均在基线。

## 任务面板

用量和任务两张弹窗的底部统一位于Windows任务栏上沿上方8 DIP，不能以任务栏内部的状态条上沿作为间距基准。复用同一个定位方法，不新增样式开关。

新增待读：只读 Codex 本机状态文件，仅提取 `electron-persisted-atom-state.unread-thread-ids-by-host-v1.local` 的任务 ID，不保存或输出其他配置，不写回 Codex 状态。只有本工具 Recent 范围内、最近一轮为 task_complete 且当前不在运行的未读任务显示橙黄色；turn_aborted 不算完成。打开任务后的已读变化以 Codex 更新该列表为准，不因发出深链接就提前标记已读。该字段是版本相关的本地格式，缺失/损坏时未读统计为未知，不伪造零或已读。

底部在 Running 数量后增加橙黄色未读计数胶囊，复用同一外形但圆点静止、不呼吸；零或未知时不显示。任务列表分区改为 Running / Recent，Recent 保留今天有活动的非运行任务范围；橙色点代表已完成未读，灰蓝点仅表示其他非运行任务。任务弹窗与底部状态条同左边界，按内容自适应且不超过状态条宽度，用量弹窗宽度保持原状。

三枚比例环作为稳定仪表，不再持续扫光、混白或跟随Token消耗闪动；实弧使用清晰绿色、紫色、蓝色，底轨保留较弱的同色轨道。仅真实占比变化使用300ms平滑过渡，时间环自然反映剩余时间。运行感保留在右侧任务呼吸点、标题和轮播。移除仅用于圆环扫光的Token活动状态与绘制，不留下另一套检测。

任务行 Token 改用该任务本机今日累计值（本地 0 点起，包含今天多轮运行；跨夜只计今天部分），不用最近一轮或整个任务的历史总量。时长为该任务本地今日累计运行时长。首次读取会利用日志基线恢复今天的数据。

任务弹窗最新宽度规则：按当前列表最长任务名的实际字体宽度，加上项目列、时长、Token 与必要间距计算；最小 260 DIP，最大不超过底部状态条。保留左边界对齐；达到上限后的长标题继续省略与悬停滚动。取代固定同宽规则。

列表分为 Running 和 Recent，各区内按最近活动倒序，空区不显示。每个任务仅一行：项目标签、任务名、今日累计时长、今日累计 Token。只保留弱化的分区名称，没有顶部列名或排序切换。不将更新时间冒充打开时间，不声称覆盖仅浏览过的任务。
列表可滚动，各列对齐，超长任务名省略号截断，悬停在任务名列内缓慢往返展示全文，不换行。运行任务用绿色呼吸点，Recent 中已完成未读用橙黄色静止点，其他非运行任务用灰蓝静止点，不使用完成勾；一轮运行结束不能解释为整个任务完成。Token 含缓存输入，不是额度百分比，按每个任务当天零点后的实际累计展示，未知仍显示未知。今日累计运行时长随运行更新，本轮结束后保留并在下轮继续累加。
用量弹窗保持 360 DIP。任务弹窗按最长任务名自适应，最小 260 DIP、最大为状态条宽度；左侧与状态条起点对齐，额外空间优先给任务名。
点击使用注册的 codex://threads/<id> 打开现有任务，不发送、恢复推理或创建任务。切换、空白和滚动不得误开任务。

## 数据合同

只读使用本机 Codex app-server 公开 API，额度每 30 秒、元数据每 5 秒、日志增量每秒；不新增 hooks，不修改 Codex、Explorer 或遥控器。
任务状态基于 task_started/task_complete/turn_aborted。独立服务的 notLoaded 不代表桌面未运行；早于本次系统启动的未结束记录排除，同次启动异常退出且无结束事件仍有不确定性，不按超时伪造结束。
今日及周期 Token 使用累计差分，含缓存、推理输出不重复计入，排除分叉创建前继承历史。只保留时间、生命周期和用量，不保存对话内容；未知、截断和部分行不编造值。
日额度使用状态条自己的记录：首次使用以当前首条额度记录为基准，立即显示 0%，累计启动以来的消耗，不包含首次启动之前。跨日后取零点后首条记录为基准。不用任务日志或 Token 估算缺失基线；跨周重置不能直接新旧百分比相减。
当天发生周重置时，保留重置前已经算出的消耗，新周期以首条采样为基准继续相减，各周期增量相加。缺失的采样间隔不估算，不假设旧周期消耗到 100%；完全没有额度数据才显示未知。
项目优先 projectId，再按最长目录根匹配，否则无项目。

## 验收

覆盖运行/结束、跨日、累计归零、迟到结束、分叉、部分行、首次额度基准和跨周重置。真实窗口验证左右入口、切换、外部关闭、不抢焦点、滚动、单位保存、点击任务跳转。受控多任务验证单行布局、排序、长标题和末行点击，与实际运行验证分开，启动项配置与实际重启分开。

日累计读取基线同时覆盖本地零点和周期起点；周额度在白天重置时，也不能混入任务历史累计或漏掉当天重置前的消耗。

底栏任务入口的点击范围按当前实际显示的计数、项目标签与任务名加少量边距计算；右侧空白不打开弹窗且不吞点击。长标题以可见裁切宽度为界，过渡时覆盖仍可见的新旧任务内容，空闲时仅保留实际Tasks入口。标题悬停范围也按可见字宽计算，空白不暂停轮播。

今日时长直接复用已有生命周期日志读取：累加本地零点后的已结束/中止轮次，加上当前运行轮次与今天的交集；轮次之间的空档不计，跨夜裁到零点。包含工具等待，不是纯模型推理时长。重复结束和前轮迟到结束不重复计时；无开始记录保持未知，不猜测缺失的结束时刻；分叉继承的轮次不计。初次尾部回溯需覆盖零点前生命周期基线，跨日/截断沿用现有重新读取机制。不增加采集器或额外日志轮询。



## 停止、失败与信息组
任务新增status=stopped/failed：stopped仅依据明确turn_aborted；失败要求只读thread/turns/list返回与日志最新turn ID一致的failed且包含错误信息。独立app-server推断的interrupted不可用作停止证据。失败不计待读、不再轮播，下轮开始自然清除。保留Running/Recent分组，状态位置分别绘制灰色停止方块、红色感叹号，不增加弹出错误提示。
复用5秒目录更新节奏：只读今日任务最新一轮、itemsView=notLoaded；仅目录更新时间、日志长度或轮次变化时重新读取，缓存结果。读取失败不是任务失败。未持久化到该接口的桌面瞬时错误仍无法捕获，不宣称覆盖全部实时错误。
时长与Token同为今日累计：时间使用柔和紫色，Token使用蓝色，动态测量两列宽度并固定12 DIP列间距；信息组前用一条淡色10 DIP短竖线，与标题保留12 DIP距离。仍是一行，不新增表头。任务窗继续内容自适应且不超过底栏。
三环统一11 DIP直径和1.4 DIP线宽，实弧绿#45BA91、紫#A088D1、蓝#5D9DD7，底轨alpha85；功能色保持稳定，不混白。

底栏任务标题按完整标题的实际字形包围盒居中到标签/计数胶囊中心；绘制、扫光、悬停滚动与切换共用该纵向位置。使用完整标题测量，省略号和横向滚动不改变垂直位置，不改字体或字号。
