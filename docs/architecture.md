# 开发与架构

Windows 11 x64 的单行 Codex 状态工具，支持任务栏与可选悬浮胶囊。当前里程碑见[Windows companion](specs/windows-companion.md)，现行交互见[交互规范](specs/interaction.md)，安装约束见[分发规范](specs/release.md)，操作步骤见[发布流程](publishing.md)。历史变化统一放在 CHANGELOG，不另存按轮次追加的交接流水账。

## 源码职责

| 模块 | 职责 |
|---|---|
| app.py、settings_ui.py | Qt 自绘状态条、各弹窗及设置 |
| i18n.py | 英文、中文、日语、西班牙语文案与无项目显示占位 |
| task_finder.py | 内存任务目录搜索、项目筛选与虚拟列表，不独立查询接口 |
| provider.py | 单个后台线程，组合额度、任务和日志结果 |
| codex_api.py | 本机 app-server 只读查询及已确认的重置请求 |
| usage.py、tasks.py | 增量 Token、时长与任务分类 |
| resets.py | 按账号保存重置事件、阶段边界及幂等操作 |
| side_chats.py | 只读关联临时侧边聊天及生命周期 |
| preferences.py、unread.py | 本机设置、旧数据迁移与未读状态 |
| windows.py、startup.py | 任务栏布局、鼠标命中和用户启动项 |
| presentation.py | 悬浮位置与面板的屏幕边界计算，使用Qt逻辑坐标 |
| updates.py、build_info.py | GitHub 更新及唯一版本来源 |

以上模块均在 codex_taskbar/。根目录 app.py 仅负责启动，start.ps1 和 PyInstaller 共用它；测试位于 tests/。

## 数据与性能

额度每30秒读取一次，目录与侧边聊天每5秒更新，普通日志每秒增量读取；共用Provider线程。UI定时器只读取已生成快照，不同步访问网络。侧边聊天只解析主进程日志中的元数据，首次关联使用SQLite时间索引查询，连接及时关闭。

150ms界面检查保留可见性恢复与交互；静态内容仅变化时重绘，任务动画只请求任务区域重绘。设置连接状态独立更新，不反复读取启动登记或重填控件。snapshot.json仅用于诊断，每30秒及正常退出时写入；内存快照与额度/重置账本不受该节流影响。

已确认的侧聊关联按桌面进程会话保存在side_chat_links.json，状态条重启时恢复，不依赖创建日志永久存在；运行状态仍来自当前会话日志，缓存写入失败不阻断实时显示。

侧聊完成后复用Codex未读ID集合：子会话未读合并到父任务并保留Side标记，读取后跟随Codex清除。主任务仍运行时不重复计数；不另存未读状态或按时间猜测已读。

Token使用累计差分，含缓存输入，按分叉创建时间排除继承用量。日、周和重置历史阶段有独立边界，复用同一个日志游标。历史总量只代表本机已收录任务，不表示跨设备账户总量或精确额度消耗。

所有用户数据都在 `%USERPROFILE%/.codex-taskbar-companion`。源码与安装目录不保存用户配置；升级、退出和重启不能重置当日统计基线。应用不保存对话正文或登录凭据。

## 界面约束

状态条胶囊按内容收窄，保留原最大宽度；按轮播中最长任务测量，切换任务不伸缩。悬浮位置保存测量参考宽度，内容改变时保持左锚点。手动深/浅配色与0%～100%背景透明度，默认深色不透明，不跟随系统主题。文字与圆环保持独立的不透明度，字号和字形共用内置阿里普惠体3.0。任务每8秒切换；悬停暂停、离开续播。透明点击区域提供非零命中像素，覆盖整块组件；胶囊空白不触发面板，外部透明区域继续穿透。

查找任务复用5秒目录更新，显式包含cli/vscode/appServer/exec来源并按ID去重，仍排除子任务。目录仅投影ID、名称、项目和更新时间，保存在内存快照中，不写诊断文件。界面只叠加已有日志证据，不把独立观察进程返回的notLoaded解释成停止或等待状态。详细合同见[任务查找](specs/task-finding.md)。

所有底栏指标缺数据时共用“—”及相同文字颜色、字号和基线，日占比没有单独的淡化或短横杠处理；未知不显示成0%。

可选额度轮换复用150ms UI tick，所有已开启左侧指标（含倒计时）共用固定宽度槽，宽度按当前倒计时格式预留，格式内固定，圆环位置不变。停留8秒后，文字与圆环以460ms完整过渡替换；点击途中可从当前进度平滑回到可见项。悬停、额度面板、设置、菜单和按下期间暂停，离开续用已等待时间。默认仍并排，不影响后台采样或任务轮播。

保留任务栏owner关系，并检查实际窗口层级。任务栏被系统抬到状态条之上时，只把状态条放回任务栏前面；不激活窗口、不改变owner层级，不在层级正常时反复置顶。Qt与原生可见/最小化/曝光状态不一致时，用Qt hide/show恢复表面；短暂曝光变化缓冲300ms，持续异常只恢复一次，恢复正常后重新允许下次修复。右键菜单归属状态条，显示在任务栏上方，避免被底栏覆盖。

所有悬浮框使用不透明深色 `#262b33`、统一圆角与8 DIP任务栏间距。单位选中态由点击决定，悬停不会切换选项。周、日小标题与日期/总量/单位分别成行。重置来源统一使用蓝色，可用次数绿色、默认项和下次时间蓝色。

重置面板最小为300 DIP，按时间、用量与分类的实际字宽补足空间，其余面板保持既有宽度。可选悬停打开共用UI定时器与鼠标事件，不增加后台采集；入口停留350毫秒打开，离开入口和面板450毫秒关闭。快速离开事件解除手动关闭后的抑制，任务标题不因悬停跳转。

重置分类按产品规则排除：自然到期、确认手动、其余归为Official推定。真实消费必须二次确认，操作先持久化幂等键；不明结果的重试复用同一个键。验证只能使用模拟消费接口。

## 验证

从根目录运行 `.venv/Scripts/python.exe -m unittest discover` 和 `.venv/Scripts/python.exe app.py --smoke-test`。构建使用scripts/package.ps1，不绕过隔离PATH或安装引导程序。检查实际安装版窗口、启动登记、更新元数据和资产校验；不能把单元测试等同于真实登录、其他电脑或消费重置验证。
