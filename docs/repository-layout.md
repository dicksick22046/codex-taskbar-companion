# 仓库目录整理

## 目标与边界

把当前应用实现和测试从仓库根目录移出，删除已被现行规范和更新记录覆盖的过程文档。保持app.py与start.ps1启动入口、安装目录、数据目录、启动登记、GitHub更新地址和既有功能不变。

## 目录

- codex_taskbar/：应用包，保存UI、数据读取、统计、系统适配、更新和唯一版本号。
- tests/：单元及集成回归，标准unittest discover可从仓库根目录执行。
- scripts/、installer/：构建脚本与安装器。
- assets/：字体与必须保留的第三方许可。
- docs/：架构、发布和审核说明；docs/specs/保存交互与分发合同。
- app.py：只调用包内main，兼容现有启动与构建入口。

包内导入使用相对路径；测试和构建脚本使用codex_taskbar包名。源码与冻结安装版都从资源根目录读取字体和许可。源码开机启动指向仓库根app.py，不能直接运行依赖相对导入的包内文件。

.runtime、.venv、.deps、build、dist、release、Python缓存、私有日志和数据库不进入Git。已有用户记录、回退资料及第三方许可证不因目录整理删除。删除旧实现副本，避免留两套源码。

## 验证

迁移前后的完整回归、根入口smoke-test、PyInstaller和Inno构建、覆盖安装、安装版实际窗口、现有设置和重置次数保留。审核包内引用、发布资产和Git跟踪文件，发布目标仍只为GitHub。
