# v0.2 分区面板与额度重置

## 点击与信息

- 周额度及可选5h额度打开既有周期图表；日额度打开Today · Tokens列表，仅保留各任务今日Token，不显示时长。
- 日列表分Running、Unread、Failed、Stopped、Recent；任务只出现一次，空分组隐藏。组内按今日Token降序，再按最近活动排序。不把本机Token解释为账户额度百分比的精确分摊。
- 状态胶囊（圆点和数量整体）只打开对应分类列表，仅显示本轮耗时，不显示Token。运行中持续计时；未读、停止、失败保留最近一轮的开始至结束时长。缺少必要时间则未知，不用今日累计时长代替。
- 底部仅在数量非零时显示Running、Unread、Failed、Stopped胶囊。保留已有状态证据边界，不增加网络失败推断。
- 项目标记与滚动标题整体点击直接打开当前任务。悬停暂停轮播，按下时固定目标，松开仍在该点击区才执行；空白、拖离不跳转。
- 同时只开一个面板；同入口再次点击关闭，不同入口切换，外部点击关闭并正常传递。无运行任务时保留Tasks作为今日列表入口。
- 所有面板复用现有字体、颜色、毛玻璃、左边界、8 DIP任务栏间距及单行任务布局，不增加常驻提示或设置项。

## 重置面板

剩余时间独立打开重置面板：下一次周期重置时间、已观测记录、使用一次重置按钮及默认机会到期时间。复用account/rateLimits/read既有30秒读取，不增加采集线程或轮询。

默认选择有效且grantedAt最新的可用机会，不按最早到期排序，不提供机会展开或选择器。界面显示这个机会的expiresAt；未知不声称永不过期。明细不完整、无法确定最新机会或账号未知时，不猜测消费对象。

点击按钮必须二次确认，明确消耗一次机会及该机会到期时间。取消不发送请求。确认后请求进入现有Provider线程串行执行，先重新读取并核对账号与选中机会；按钮立即进入处理中，防止重复提交。

每次操作在请求前持久化账号、creditId与UUID幂等键。超时或连接结果不明时保留同一次请求；后续用户明确确认重试才继续，重试不得换机会或换幂等键。启动程序不会自动消费机会。账号切换不能执行其他账号的未决请求。

只有reset或alreadyRedeemed才记Manual，并重新读取额度；noCredit、nothingToReset不记成功。未知结果不标成功。错误只记本机日志，操作按钮提供可重试状态，不弹全局提示。

## 记录与数据

记录按账户分开保存在用户数据目录，保留最近100条。新版本开始观察，不把无账户归属的旧采样拼成完整历史。每条时间为确认或观察时间。

- Scheduled：已知窗口到期并观察到下一周期。
- Manual：本工具的重置请求已确认成功。
- Official：仅允许有明确官方来源的记录；当前接口未提供原因，不据额度下降伪造官方记录。
- Unknown：非已知周期切换的额度重置/下调，来源不能确认。

赠送重置机会不等于额度已重置。无法判定的外部操作保留Unknown。重置过程中观察到的窗口变化合并到同一操作，不重复记为Manual与Unknown。发生同一窗口内用量下调时，今日消耗保留此前已观察到的正增量。

## 验证

分类互斥、空组隐藏、日Token与本轮时间口径、点击分区/按下目标固定/拖离取消、列表跳转、重置最新选择和到期、二次确认取消、重复点击、超时重试幂等、重启/账号切换、自然与未知记录、同窗口重置后的今日累计均需针对性验证。

严禁验证时消费用户真实重置机会。真实接口只读；真实确认框只允许取消。确认后的成功/失败/重试使用模拟API，测试记录与用户数据隔离。最后构建安装版验证可见交互，再发布新版本。

接口依据：[Codex App Server](https://learn.chatgpt.com/zh-Hans/docs/app-server)，account/rateLimits/read与account/rateLimitResetCredit/consume。
