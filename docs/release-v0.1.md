# v0.1 首版范围与验收

## 产品
面向Codex桌面重度用户的Windows极简任务状态条。Windows11 x64、底部主任务栏、左侧优先；不提供macOS、多服务商、成本仪表盘、自由样式编辑。网络失败实时扩展已由用户取消，保留现有明确停止/失败结果。

## 使用合同
右键状态条或系统托盘仅提供设置和退出；开机启动与更新统一放在设置内，避免重复入口。设置只含周额度、5小时额度、倒计时、今日消耗、任务区域五项，默认开启，5小时仅在接口提供时显示；立即生效保存。所有项关闭后托盘仍可恢复，不退出后台。托盘左键打开设置；再次从开始菜单启动时打开已有实例的设置，不无声退出或另起一份。
按实际窗口300/10080分钟取额度，不按套餐硬编码。双窗口时标注5h/7d；倒计时默认周窗口，5小时摘要在用量面板独立显示剩余与重置倒计时。日消耗始终以周额度为分母；没有周窗口时不伪造该值。图表周期优先周，其次实际提供的短窗口。
常态保留已有单行布局、原生毛玻璃、平稳指标、任务轮播与字形居中。字体保留阿里普惠体，保留原始版权、来源、哈希和官方免费商用说明，不套用本项目MIT许可。
任务栏空间不足优先缩减任务可见范围，不遮挡系统按钮；不适用的布局可收起到托盘。主屏之外或第三方任务栏不宣称支持。首次无Codex或连接故障，在设置中提供简洁状态，后台不反复弹错误；数据失败时指标不得冒充实时。

## 分发与数据
版本单一来源，首个开发交付为0.1.0。每用户安装，不要求管理员权限。应用代码与数据分离：用户数据置USERPROFILE/.codex-taskbar-companion，开发版历史仅迁移已知设置和额度记录。升级和卸载默认保留用户数据，重新安装继续使用。
采用PyInstaller目录包、Inno Setup安装器，保留可替换的Qt库和第三方许可；安装包不含账号、日志、会话、开发环境或个人截图。使用系统注册启动项，可在应用中取消。
GitHub正式Release为更新来源，后台启动和每24小时检查，右键可手动检查；新版本每版本提醒一次，用户选择安装，旧版本配置保留。下载与完整性校验在后台；地址必须限定到配置的仓库发布资产，不能执行任意响应URL。没有配置发布仓库时明确说明未配置，不假称已是最新版。代码推送不等于发布。对外发布与远端创建需明确目的地及授权；当前不擅自公开。

## 验收
既有数据/交互测试通过；增加5h/周/空数据、多开关全关恢复、设置持久化、更新版本解析和资产校验测试。实机验证主条左右入口、右键设置、托盘恢复、安装后运行、升级保留设置、卸载保留记录。使用隔离目录测试安装卸载，避免破坏现有工作实例。无Mac、Win10或新电脑实测不得声称通过。


## 启动方式无关的数据目录修正
Windows会将从MSIX宿主启动的程序对LocalAppData的访问重定向到宿主LocalCache，导致开发/安装启动与登录启动读写不同记录。数据目录改为USERPROFILE/.codex-taskbar-companion，已用文件句柄实际路径核对不受该重定向影响。
启动时合并旧独立LocalAppData、各宿主LocalCache及开发目录中已知的额度记录，相同内容不重复写入，按采样时间和周期去重，配置取最近可用文件；旧文件保留。已有新目录记录不被旧记录覆盖。迁移在单实例锁之后执行，额度记录采用原子写入，防止退出中断将文件写成半份。
重启不得重置当日基线；仍按当天首条记录和实际周重置累加，跨日才使用新一天的基线。


## 短暂读取失败时的显示
任务元数据或附加状态读取失败不能抹掉仍有效的额度。额度失败或空响应时保留最近成功数据，显示保持原样，不调暗；设置中说明当前为上次记录。超过其重置时间的旧窗口显示未知，不假称新周期余额。额度成功后正常更新。失败按来源记录到本机日志，不弹错误窗；额度重试仍使用既有30秒节奏，附加任务状态失败不重启整个采集连接。
