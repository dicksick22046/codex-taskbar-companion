## 安装

需要 **Windows 11 x64**，并已安装、登录 **Codex 桌面版**。

1. 从 [Releases](https://github.com/dicksick22046/codex-taskbar-companion/releases/latest) 下载 `CodexTaskbarCompanion-版本号-Setup-x64.exe`。
2. 安装并启动。安装包包含 Python、Qt 和字体，不需要另外配置环境或管理员权限。
3. 右键状态条打开设置，选择显示项目和是否开机启动。

新安装默认使用**自动**摆放：优先主任务栏，空间不足时悬浮；升级保留已有位置选择。右键状态条、任务条或托盘，可进入查找任务、任务状态分类、设置和退出。更新从 GitHub 检查，由你选择是否安装。

设置里的**状态条位置**控制额度与状态数量条。**进行中任务悬浮条**可独立开启、拖动和记忆位置；**悬浮窗口保持置顶**作用于启用的悬浮窗口，配色与透明度共用。

**自动**模式优先使用主任务栏，空间不足时转为悬浮窗，空间稳定恢复后返回，并避让前台全屏应用。**悬浮显示器**可跟随主屏或固定一块屏幕；断开时临时回主屏，重连后恢复原相对位置。目前没有新增副任务栏嵌入，也不因此宣称已验证其他 Windows 版本。

## 使用

| 点击位置 | 查看内容 |
| --- | --- |
| 周额度 | 当前额度周期每天的 Token 用量 |
| 今日额度消耗 | 按任务和状态分类的今日 Token 用量 |
| 5h 额度（账户提供时） | 剩余额度、重置时间和已记录的余额变化 |
| 重置倒计时 | 重置历史和可用的重置机会 |
| 状态圆点与数量 | 该状态的任务，以及当前或最近一轮的耗时 |
| 任务标题 | 在 Codex 中打开该任务 |

新用户默认保留任务状态数量，关闭独立任务悬浮条；升级保留已有显示选择。两者可在显示项中分别开关。任务悬浮条开启后以固定宽度轮播进行中任务，悬停暂停切换并展开长标题，无进行中任务时隐藏。主侧线标记只用于即时任务展示；点击侧聊回父任务，不在统计或搜索中增加重复行。运行标记保持静态，动效只用于操作反馈、切换和主动阅读长标题。

设置中可切换英文、简体中文、日语和西班牙语，也可开启悬停打开面板或额度轮换。轮换时，已开启的本周、今日、5h和重置倒计时共用一个固定宽度位置。

胶囊配色和背景透明度可在设置中手动调整。深浅两套配色，0%透明度表示不透明背景；文字和圆环不会一起变淡。

右键选择 **查找任务…**，可按任务名、项目名搜索，并筛选项目；点击结果或用方向键和回车返回 Codex 中的任务。筛选只作用于查找窗口，不改变底栏统计口径。搜索在本地完成，不保存搜索词。

状态条按实际文案与数量适配可用空间，不再受固定540 DIP上限约束，也不悄悄改变额度轮换设置或隐藏已选指标。完整内容确实放不下时，托盘和右键的任务状态菜单仍可用。任务悬浮条轮播时保持稳定宽度。

## 数据怎么算

查找默认展示项目、名称、状态和最近活动。开启**历史统计**后，才展示本机累计运行时长、Token、执行轮次及单位切换。保留搜索、筛选和选择；收起统计或关闭窗口会暂停历史整理，已有缓存保留。时长包括轮内等待、排除轮间空档；轮次不是消息或工具调用次数，`≥`表示已知下限。

设置通过侧栏切换「外观、显示项、常规」。显示位置、配色和显示项立即生效，胶囊宽度也随之调整。「常规」里可开启默认关闭的待回答通知，或复制不含任务名、账号、路径和日志内容的诊断信息。

日志中明确未回答的同步提问会显示「待回答」和琥珀色问号，点击返回 Codex 回答；异步问题、未保存的侧聊和人工审批尚不能全部识别。通知会合并新出现的等待任务，不反复提醒相同状态。

![设置分组](../images/settings.png)

![待回答提示（演示数据）](../images/attention.png)

- 百分比来自账户，Token 来自本机记录，详情会分别标明来源，不能精确互换。读取失败时用「上次记录」标记保留值，并显示最后更新时间；过期余额与重置时间在各处统一显示未知。
- 本周与5h显示剩余，今日显示已记录消耗，并在详情标明当天观测起点。它可能不是完整全天；重启保留基线，不补算缺失区间，跨重置分段累计。
- 日列表统计今天的多轮任务用量；状态列表显示当前或最近一轮的耗时，包含工具等待时间。
- 历史 Token 只统计本机已记录的任务，不包含其他设备，以及没有保存用量的临时侧边聊天。

重置历史分为自然、手动、官方三类。排除自然到期和本工具已确认的手动重置后，其他额度恢复归为官方；这是根据观测推定的分类，不是平台直接提供的来源。Token只作一次列标题，每行保留数值和单位。使用重置机会仍需二次确认，会消耗真实机会。

## 数据保存与限制

设置、任务名称和用量记录保存在 `%USERPROFILE%/.codex-taskbar-companion`，更新和卸载都会保留。工具不保存对话正文或账号凭据，没有遥测。提交截图和日志前，请去掉私人信息。

目前是 Windows 11 的早期版本。Windows 10、macOS、多屏独立状态条和第三方任务栏未验证，安装包尚未代码签名。侧边聊天依赖 Codex 桌面日志，日志格式变化后可能需要更新适配。暂时读取失败会保留有效数据，但无法捕获 Codex 的所有瞬时错误。

## 开发

需要 Python 3.12；打包还需要 Inno Setup。

```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv/Scripts/python.exe -r requirements-build.txt
./start.ps1
.venv/Scripts/python.exe -m unittest discover
./scripts/package.ps1 -Compiler 'C:/Path/To/Inno Setup/ISCC.exe'
```

运行源码前先退出安装版，重复启动会打开已有实例的设置。构建结果在 `dist/` 和 `release/`，版本号位于 `codex_taskbar/build_info.py`。

没有 5h 额度的账号可运行 `./scripts/preview-session.ps1`，用独立窗口里的模拟数据预览，不修改账号或设置。
